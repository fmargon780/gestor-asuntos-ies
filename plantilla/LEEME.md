# Plantilla del método de trabajo

Esta carpeta no forma parte de la aplicación. Es el punto de partida para **proyectos nuevos**.

Al arrancar un proyecto nuevo, se copian estos cinco ficheros a la carpeta `docs/` del
repositorio nuevo, quitándoles el `.plantilla` del nombre:

| De aquí | Al repositorio nuevo |
|---|---|
| `CONTEXTO-CORTO.plantilla.md` | `docs/CONTEXTO-CORTO.md` |
| `CONTEXTO.plantilla.md` | `docs/CONTEXTO.md` |
| `HISTORIA.plantilla.md` | `docs/HISTORIA.md` |
| `COLA.plantilla.md` | `docs/COLA.md` |
| `AHORRO-CUOTA.plantilla.md` | `docs/AHORRO-CUOTA.md` |

Y el texto de `INSTRUCCIONES-PROYECTO.plantilla.md` se pega en las instrucciones del proyecto
de Claude, cambiando el nombre del repositorio y la dirección publicada.

Los huecos marcados con `<...>` se rellenan con lo que se haya hablado en la conversación.
